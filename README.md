# Arch KDE Gaming Setup

A production-grade Arch Linux bootstrap for KDE Plasma gaming systems.

## Features

* KDE Plasma (lightweight tuned)
* Zen Kernel (low latency)
* Auto GPU detection (NVIDIA / AMD / Intel)
* Steam + Lutris + Heroic
* Proton GE support
* MangoHud + GameMode
* Flatpak + Flathub
* SSD + sysctl optimization
* Virtualization (QEMU + Virt-Manager)
* Git-based update system

---

# Clone the repository
git clone https://github.com/YOUR_USERNAME/arch-extreme-gaming.git

# Enter the project directory
cd arch-extreme-gaming

# Make the installer executable
chmod +x install.sh

# Run the installer
./install.sh

## Update

```bash
./update.sh
```

---

## Requirements

* Fresh Arch install (archinstall → Minimal)
* Internet connection
* Run from TTY (no desktop environment installed)
